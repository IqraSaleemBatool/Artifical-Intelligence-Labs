# Minimax Game AI — Tic-Tac-Toe & Connect 4

Two classic two-player games solved with the **Minimax algorithm**,
enhanced with **Alpha-Beta Pruning** and **Graphviz tree visualization**.

Built as part of an *Introduction to AI* course.

##  Games Included

| Game | Board | Algorithm | 
|------|-------|-----------|
| Tic-Tac-Toe | 3×3 | Minimax | 
| Connect 4 | 6×7 | Minimax + Alpha-Beta | 

##  Concepts Covered

- **Minimax** — MAX (AI) vs MIN (human), full game-tree search
- **Heuristic evaluation** — window scoring for non-terminal states
- **Alpha-Beta Pruning** — pruning branches where α ≥ β
- **Tree visualization** — Graphviz export of explored nodes
